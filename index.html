Trainer App

Assign trainers, open trainee profiles, check off day-by-day training steps, add shift logs, score categories, and hold trainers accountable.

Position Training Packets

Orientation, Server, Host, Bartender, and To-Go training paths are built into the app from the current materials. Each path can create checklists, sign-offs, quiz items, and manager wait forms.

Built-In Manual Library

Full editable training library. Use View Mode on shift, or Edit Mode to revise wording without touching code. Saved locally now; later this will sync to Google Sheets/Firebase.

Forms, Emails & Module Sender

Send welcome emails, training module reminders, manager wait forms, availability forms, commitment forms, and follow-up notes directly from the app using email drafts. Full automated sending comes later through Apps Script/Gmail.

Document Vault

Upload PDFs, sheets, forms, training packets, images, and files. Small files save inside the browser using IndexedDB. Permanent multi-device storage should be Firebase Storage or Google Drive after backend connection.
